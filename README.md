# hamster-tg

一个 Telegram Bot，用于将图片、视频、GIF 和文件批量保存到本地。基于本地 Telegram Bot API 服务，支持大文件（最大 2GB）。

## 功能

- 保存图片、视频、GIF 和文件到本地目录
- 批量转发（相册/媒体组）只回复一条汇总消息
- 保存时显示"上传中"状态
- 保存失败时显示具体错误、实际尝试次数，并提供「重试失败文件」按钮
- 通过 `/new` 或 `/newfolder` 切换保存目录，按来源或主题分类整理
- 通过 `/list` 查看最近修改的 10 个文件夹
- 文件名冲突时自动追加 `_1`、`_2` 等后缀，不会覆盖已有文件

## 本地运行

```bash
uv run python -m hamster_tg
```

## Bot 命令

| 命令 | 说明 |
|------|------|
| `/start` | 显示帮助信息 |
| `/new <名称>` | 创建并切换到指定文件夹 |
| `/newfolder <名称>` | 创建并切换到指定文件夹 |
| `/list` | 查看最近修改的 10 个文件夹 |
| `/status` | 查看当前文件夹和已保存文件数 |
| 直接发送媒体 | 自动保存到当前文件夹 |

文件夹名称支持字母、数字、中文、`-` 和 `_`。

保存遇到网络错误时会自动尝试最多 6 次；磁盘空间、权限等本地错误会直接反馈。
点击失败消息下方的「重试失败文件」即可再次保存，无需重新发送媒体。
相册只重试失败的文件，仍保存到原来的目录，不受后续切换目录影响。
重试成功后移除按钮，再次失败则更新错误并保留按钮；重复点击不会重复启动任务。
按钮记录保存在内存中，有效期 24 小时，最多保留 1000 条；机器人重启或记录过期、被淘汰后需重新发送文件。
可通过环境变量 `RETRY_REQUEST_TTL_SECONDS`（默认 `86400` 秒）和 `RETRY_REQUEST_MAX_ENTRIES`（默认 `1000`）调整。
如果 Telegram 本身不可用，错误通知也可能发送失败，此时请查看机器人日志。
