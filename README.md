# hamster-tg

一个 Telegram Bot，用于将图片、视频、GIF 和图片/视频文件批量保存到本地。基于本地 Telegram Bot API 服务，支持大文件（最大 2GB）。

## 功能

- 收到媒体后持久化入队，默认同时处理 2 个文件，保存期间仍可响应命令
- 保存图片、视频、GIF 和图片/视频文件到本地目录
- 批量转发（相册/媒体组）只回复一条汇总消息
- 保存时显示"上传中"状态
- 保存失败时显示具体错误、实际尝试次数，并提供「重试失败文件」按钮
- 通过 `/new` 或 `/newfolder` 切换保存目录，按来源或主题分类整理
- 通过 `/list` 查看最近修改的 10 个文件夹
- 文件使用 `file_N` 命名，不覆盖已有文件；同目录按内容去重，区分新增、已存在和失败
- SQLite 保留目录选择、哈希索引、待办及失败重试记录，重启后继续处理
- 首次启动自动导入已有目录，支持 `/scan` 重复扫描和查询进度

## 本地运行

```bash
uv run python -m hamster_tg
```

## Bot 命令

| 命令 | 说明 |
|------|------|
| `/start` | 显示帮助信息 |
| `/new <名称>` | 创建并切换到指定文件夹 |
| `/newfolder <名称>` | 创建并切换到指定文件夹 |
| `/list` | 查看最近修改的 10 个文件夹 |
| `/status` | 查看当前目录、已登记文件数、等待/处理中数量和并发数 |
| `/scan [目录名]` | 扫描全部或指定目录并更新索引；运行中再次发送返回进度 |
| 直接发送媒体 | 自动保存到当前文件夹 |

文件夹名称支持字母、数字、中文、`-` 和 `_`。

保存遇到网络错误时会自动尝试最多 6 次；磁盘空间、权限等本地错误会直接反馈。
点击失败消息下方的「重试失败文件」即可再次保存，无需重新发送媒体。
相册只重试失败的文件，仍保存到原来的目录，不受后续切换目录影响。
重试成功后移除按钮，再次失败则更新错误并保留按钮；重复点击不会重复启动任务。
重试记录保存在 SQLite 中，有效期 24 小时，最多保留 1000 个有效按钮；重启后未过期按钮仍可使用，记录过期或被淘汰后需重新发送文件。按钮清理不会删除文件或未完成任务。
可通过环境变量 `RETRY_REQUEST_TTL_SECONDS`（默认 `86400` 秒）和 `RETRY_REQUEST_MAX_ENTRIES`（默认 `1000`）调整。
如果 Telegram 本身不可用，错误通知也可能发送失败，此时请查看机器人日志。

## 并发、迁移和扫描

`DOWNLOAD_CONCURRENCY` 默认为 `2`，可设置为其他正整数。所有消费者共享 API 限速，复制和哈希计算在线程中执行。

数据库保存在 `DOWNLOAD_ROOT/.hamster.sqlite3`，媒体仍保留在原目录。Docker 中数据库与媒体一起持久化到宿主机 `./downloads`。初版仅支持一个机器人进程访问该下载目录，数据库及其 WAL 文件需位于本机文件系统。

保存通过同文件系统硬链接发布完整文件，避免覆盖已有路径；下载目录所在文件系统需要支持硬链接。

首次启动会在线程中扫描已有的一层保存目录，登记路径、大小、修改时间和 SHA-256，并初始化文件编号。保留原文件名、历史重复文件和空目录，不移动或删除媒体。目录首次索引完成前，其保存任务会等待；其他已就绪目录可以继续处理。导入中断后重启会继续利用已提交结果。

`/scan` 可反复执行，未变化文件复用已有哈希；新增和变化文件重新校验，完整扫描后将找不到的文件标记为缺失。失败或中断不会执行缺失清理。临时文件、符号链接和更深的子目录会跳过，文件夹内的跳过项计入汇总。扫描失败的目录可修复权限等问题后再次 `/scan <目录名>`。

扫描采用单独的工作线程；运行中再次执行 `/scan` 只返回进度。同目录的最终保存和快速去重判断与扫描互斥，其他目录不共享该锁。直接在磁盘上改动文件后，请执行 `/scan` 同步索引；文件数以已登记索引为准。

旧版只存在内存中的目录选择和失败按钮无法通过磁盘扫描还原；首次升级后需重新选择目录、重新发送旧失败文件。后续状态会持久化。扫描无法推断旧文件的 Telegram 标识或原始消息。

重启恢复按文件进行，保留已完成文件和尝试次数，未完成文件可以重新执行；不提供字节级断点续传。保存与通知分别记录，通知失败不会重新下载；Telegram 发送成功但通知状态尚未提交时中断，恢复后可能重复通知一次。

实现约束见 [SQLite 与队列设计](docs/sqlite-queue-design.md)。
